# 📊 Retail Data Analysis Project

## Overview
This project demonstrates a complete retail analytics solution using **Power BI**, **Zapier**, and a **promotional marketing poster**. It showcases how retail data can be transformed into actionable insights, automated workflows, and engaging marketing content.

## Project Components

### 📈 Power BI Dashboard
An interactive dashboard for analysing retail business performance through:
- Sales and Profit Analysis
- Product Category & Sub-Category Performance
- Shipping Cost Analysis
- Province-wise Sales Distribution
- Yearly Profit Trends
- Order Priority Analysis
- Interactive Charts (Bar, Line, Pie, Funnel, Waterfall, and Column)
- <img width="896" height="490" alt="dashboard" src="https://github.com/user-attachments/assets/a0918b3e-a279-42e7-8385-aedce430eba6" />


### ⚡ Zapier Automation
A workflow built using Zapier to automate data processing:
- Trigger: New Google Form Response
- Action 1: Update Google Sheets
- Action 2: Update another Google Sheets row
- Reduces manual work and keeps data synchronized automatically.

### 🎨 Promotional Poster
A marketing poster created to showcase the Retail Data Analysis solution by highlighting:
- Business insights
- Dashboard features
- Benefits of data-driven decision-making
- Professional branding for presentations and promotions

## 🛠️ Technologies Used
